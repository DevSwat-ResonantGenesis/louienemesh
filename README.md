## 🚀 Deployment Instructions

### Prerequisites
- **Server**: Linux (Ubuntu 20.04+ recommended) with minimum 8GB RAM, 4 CPU cores
- **Docker**: Version 20.10+
- **Docker Compose**: Version 2.0+
- **PostgreSQL**: Managed database service (DigitalOcean Managed Database, AWS RDS, etc.)
- **Redis**: Managed Redis service (DigitalOcean Spaces, AWS ElastiCache, etc.)
- **Object Storage**: S3-compatible storage (DigitalOcean Spaces, AWS S3, MinIO, etc.)
- **Domain**: SSL certificate configured
- **Email**: SMTP service for notifications

#### 3. Configure Environment Variables
```bash
cd ORG_Core
cp .env.production.template .env.production
# Edit .env.production with your actual values
```

**Required Environment Variables:**
- Database connections (PostgreSQL managed service - single cluster with multiple databases)
- Redis connection string (DigitalOcean Spaces or equivalent managed Redis)
- Object Storage credentials (S3-compatible storage like DigitalOcean Spaces, AWS S3, MinIO)
- JWT secret keys
- API keys for LLM providers (OpenAI, Anthropic, Groq, etc.)
- Stripe API keys
- Email SMTP configuration
- Encryption keys

**Database Architecture Note:**
All services share a single PostgreSQL managed database cluster with separate databases for each service. Table count should be calculated to ensure optimal performance before deployment.

#### 4. Build Docker Images
```bash
cd ORG_Core
./scripts/build_all.sh
```

#### 5. Deploy Using Docker Compose
```bash
docker compose -f docker-compose.unified.yml up -d
```

#### 6. Verify Deployment
```bash
# Check service status
docker compose -f docker-compose.unified.yml ps

# Check logs
docker compose -f docker-compose.unified.yml logs -f

# Run health checks
./scripts/health_check.sh
```

#### 7. Configure Nginx Reverse Proxy
```bash
# Update nginx configuration
cd nginx/sites-available/
# Edit your domain configuration
sudo nginx -t
sudo systemctl reload nginx
```

### Manual Deployment (Single Service)

For deploying individual services:
```bash
cd /path/to/service
git pull origin main
sudo docker build -t service_name .
sudo docker stop service_name && sudo docker rm service_name
sudo docker run -d --name service_name --restart unless-stalled \
  --network resonant_network \
  --env-file /path/to/.env.production \
  service_name:latest
```

### Adding Optional Services

To include optional services in deployment:
1. Clone the additional repositories
2. Add them to `docker-compose.unified.yml`
3. Update environment variables
4. Rebuild and redeploy
